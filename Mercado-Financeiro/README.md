# Stock Market

## Overview

Power BI dashboard for a comparative analysis of stocks traded on NASDAQ.

## Companies Analyzed

- IBM
- Microsoft
- Oracle
- Tesla
- Walmart

## Period Analyzed

February 2022 to February 2023.

## Objectives

- Compare company performance over the period
- Analyze the behavior of stock prices
- Assess trading volume
- Evaluate the risk–return profile of each stock

## Key Metrics

- Current Price
- Cumulative Return
- Average Daily Volume
- Period High
- Period Low
- Growth of $100 Invested

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling

## Data Source

Historical data from NASDAQ, used for educational purposes and project development.
