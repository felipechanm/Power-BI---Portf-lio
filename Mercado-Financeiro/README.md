# Mercado Financeiro

## Visão Geral

Dashboard desenvolvido em Power BI para análise comparativa de ações negociadas na NASDAQ.

## Empresas Analisadas

- IBM
- Microsoft
- Oracle
- Tesla
- Walmart

## Período Analisado

Fevereiro de 2022 a Fevereiro de 2023.

## Objetivos

- Comparar o desempenho das empresas no período
- Analisar o comportamento dos preços das ações
- Avaliar volume de negociações
- Identificar oportunidades de investimento

## Principais Indicadores

- Preço Atual
- Retorno Acumulado
- Volume Médio Diário
- Máxima do Período
- Mínima do Período
- Evolução de US$100 Investidos

## Ferramentas Utilizadas

- Power BI
- Power Query
- DAX
- Modelagem de Dados

## Fonte dos Dados

Dados históricos extraídos da NASDAQ para fins educacionais e desenvolvimento do projeto.
